> Markdown 是一种轻量级标记语言。它使用少量符号表达标题、强调、链接、图片和代码等结构，适合用来编写技术文档与 Obsidian 笔记。

## 1. 标题

在文字前添加 `#` 可以创建标题，`#` 的数量代表标题层级：

```markdown
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
```

## 2. 文本样式

| 写法           | 效果        | 用途        |
| ------------ | --------- | --------- |
| `**粗体**`     | **粗体**    | 强调关键词     |
| `*斜体*`       | *斜体*      | 补充说明、术语   |
| `***粗斜体***`  | ***粗斜体*** | 强烈强调      |
| `~~删除线~~`    | ~~删除线~~   | 标记废弃内容    |
| `==高亮==`     | ==高亮==    | 标记重点      |
| `` `行内代码` `` | `行内代码`    | 命令、变量或文件名 |

## 6. 行内代码与代码块

### 行内代码

使用一对反引号包裹短代码。例如，使用 `colcon build` 构建 ROS 2 工作空间，使用 `source install/setup.bash` 加载环境。

### 多行代码块

三个反引号可以创建代码块。在开头标注语言名称可以启用语法高亮。

```python
def greet(name: str) -> str:
    """生成一条问候语。"""
    return f"Hello, {name}!"


if __name__ == "__main__":
    print(greet("Markdown"))
```

## 7. 网页链接

基本写法为 `[显示文字](网址)`：

- [Markdown 官方语法说明](https://daringfireball.net/projects/markdown/syntax)
- [Obsidian 官方帮助文档](https://help.obsidian.md/)
- 自动链接：<https://www.ros.org/>

如需添加鼠标悬停提示，可以写成：

```markdown
[Obsidian](https://obsidian.md/ "Obsidian 官方网站")
```

## 8. Obsidian 内部链接

使用双方括号链接 Vault 内的其他笔记：

- `[[技术/语法基础/Python入门]]` → [[技术/编程基础/Python入门]]
- `[[技术/ROS与仿真/ROS2常用复制粘贴#常用复制粘贴]]`：链接到指定标题

在链接前添加 `!` 可以嵌入另一篇笔记或其中的某个章节：

```markdown
![[笔记名称#章节名称]]
```

## 9. 图片

### 本地图片

为了同时兼容 Obsidian 和 GitHub，本地图片统一使用标准 Markdown 语法。路径相对于当前 Markdown 文件：

```markdown
![图片说明](../../Assets/ros2-tips/cover.png)
```

实际显示效果：

![ROS2 笔记封面](../../Assets/ros2-tips/cover.png)

标准 Markdown 本身不支持指定图片宽度；如需跨平台显示，通常让渲染器自适应宽度。

### 网页图片

标准 Markdown 图片语法如下：

```markdown
![图片说明](https://example.com/image.png)
```

> 网页图片依赖网络和原网站。重要图片最好下载到 Vault，再使用 `![图片说明](相对路径/图片.png)` 嵌入。

## 10. 表格

Markdown 表格使用竖线 `|` 分隔每一列，使用换行分隔每一行。基本结构由三部分组成：

1. 第一行：表头；
2. 第二行：分隔线，决定每列的对齐方式；
3. 后续行：表格内容。

下面是表格的 Markdown 原文：

```markdown
| 姓名 | 学科 | 成绩 |
| --- | --- | --- |
| 小明 | 数学 | 95 |
| 小红 | 语文 | 90 |
```

渲染效果如下：

| 姓名 | 学科 | 成绩 |
| --- | --- | --- |
| 小明 | 数学 | 95 |
| 小红 | 语文 | 90 |

分隔线中的冒号用于控制对齐方向：

```markdown
| 左对齐 | 居中 | 右对齐 |
| :--- | :---: | ---: |
| 内容 A | 内容 B | 内容 C |
```

| 左对齐 | 居中 | 右对齐 |
| :--- | :---: | ---: |
| 内容 A | 内容 B | 内容 C |

- `:---`：左对齐；
- `:---:`：居中；
- `---:`：右对齐。

> 每行的列数最好保持一致。两端的竖线可以省略，但全部保留通常更清晰，也更方便编辑。

如果单元格内容本身需要显示竖线，应使用反斜杠转义：

```markdown
| 表达式 | 含义 |
| --- | --- |
| `A \| B` | A 或 B |
```

在单元格中写成 `A \| B`，才能避免 `|` 被误认为新的列分隔符。

## 11. Callout 提示框

Obsidian 支持多种 Callout：

> 用于补充普通信息。

> 用于提供背景或参考资料。

> 操作已经成功完成。

> 执行危险操作前应当备份数据。

> 记录可以稳定复现的异常现象。

Callout 还可以折叠：

> 在类型后添加 `-`，默认保持折叠；添加 `+`，默认保持展开。

## 14. 注释与转义

Obsidian 注释不会出现在阅读视图中：

```markdown
%% 这是一段仅在编辑模式可见的注释。 %%
```

%% 这是本笔记中的实际注释，在阅读视图中不会显示。 %%

当需要显示 Markdown 特殊符号本身时，可以使用反斜杠转义：

```markdown
\*这不是斜体\*
\# 这不是标题
```

实际效果：\*这不是斜体\*，\# 这不是标题。

## 15. 添加笔记属性（Properties）

笔记属性用于保存标题、标签、日期、状态和别名等结构化信息。属性位于笔记最上方，在 Markdown 源文件中以 YAML Frontmatter 的形式保存。

### 通过 Obsidian 界面添加

1. 打开需要添加属性的笔记。
2. 点击笔记顶部的 **添加属性**。
3. 输入属性名称，例如 `status`、`date` 或 `tags`。
4. 点击属性名称旁的类型图标，选择文本、列表、数字、复选框、日期或日期时间等类型。
5. 输入属性值，Obsidian 会自动将它保存到笔记顶部。

也可以打开命令面板 `Ctrl + P`，执行 **添加文件属性** 命令。

### 手动编写 YAML 属性

在笔记第一行输入三个连字符 `---`，填写属性后，再用三个连字符结束：

```yaml
---
title: Markdown 笔记
aliases:
  - Markdown 语法速查
tags:
  - Markdown
  - Obsidian
date: 2026-08-09
status: 进行中
rating: 5
published: false
---
```

Frontmatter 必须位于文件最开头，前面不能存在标题、空行或其他正文。

### 常见属性类型

| 类型 | 示例 | 适用场景 |
| --- | --- | --- |
| 文本 | `status: 进行中` | 状态、作者、来源 |
| 列表 | `tags: [Markdown, Obsidian]` | 标签、别名、相关主题 |
| 数字 | `rating: 5` | 评分、数量、优先级 |
| 复选框 | `published: false` | 是否完成、是否发布 |
| 日期 | `date: 2026-08-09` | 创建或更新日期 |
| 日期时间 | `deadline: 2026-08-09T18:30:00` | 精确的计划时间 |

列表也可以写成多行形式：

```yaml
tags:
  - ROS2
  - Gazebo
aliases:
  - Markdown 教程
  - Markdown 速查表
```

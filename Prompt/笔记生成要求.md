笔记的标题无需作为一级标题出现，否则会导致真正的一级标题变成二级标题

每一个标题，段落（换行就算段落），图片，公式的上下都应该有空行，从而保持美观，就如同这篇笔记一样

所有格式类似如下的：

```
>  [!IMPORTANT]
> `git add` 只是把修改放入暂存区，`git commit` 才会生成本地提交，`git push` 则把本地提交上传到远程仓库。
```

都要改成：

```
> `git add` 只是把修改放入暂存区，`git commit` 才会生成本地提交，`git push` 则把本地提交上传到远程仓库。
```

不需要前面的`>  [!IMPORTANT]`

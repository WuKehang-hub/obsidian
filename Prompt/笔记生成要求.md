笔记的标题无需作为一级标题出现，否则会导致真正的一级标题变成二级标题

每一个标题，段落（换行就算段落），图片，公式的上下都应该有空行，从而保持美观，就如同这篇笔记一样

所有格式类似如下的：

```
>  [!IMPORTANT]
> `git add` 只是把修改放入暂存区，`git commit` 才会生成本地提交，`git push` 则把本地提交上传到远程仓库。
```

都要改成：

```
> `git add` 只是把修改放入暂存区，`git commit` 才会生成本地提交，`git push` 则把本地提交上传到远程仓库。
```

不需要前面的`>  [!IMPORTANT]`

文章里若有图片，则在附件里新建一个文件夹，把同一个文章里的图片放入其中，注意：无论是文件夹还是图片名称都是英文。例如运控论文学习这篇文章里有两张图片，那么需要在附件里新建一个文件夹名为运控论文学习的英文名（英文名应该短、明确、稳定，而不是追求完整翻译）里面的两张图片分别命名为图片的内容（如RMA和HIM）。

图片引用统一使用标准 Markdown 图片语法而不是obsidian语法防止换个软件无法渲染。

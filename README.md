
这是我的个人 Obsidian 知识库，笔记内容以学习记录、技术总结和个人思考为主，会随着学习与实践持续更新。

## 目录结构

```text
.
├── 技术/       # 工具、算法、ROS、仿真等技术笔记
├── 生活/       # 生活记录
├── 随笔/       # 个人随笔
├── Prompt/     # AI Prompt
└── Assets/     # 图片及其他附件
```

## 使用方式

1. 克隆仓库：

   ```bash
   git clone <repository-url>
   ```

2. 安装并打开 [Obsidian](https://obsidian.md/)。

3. 选择“打开本地仓库”，然后选择克隆得到的文件夹。

## Git 同步说明

以下本地数据已通过 `.gitignore` 排除，不会上传到 GitHub：

- `.obsidian/`：Obsidian 插件、界面和工作区配置
- `.claudian/`：Claudian 设置、会话和对话记录
- `.DS_Store`、`Thumbs.db`：操作系统自动生成的文件

因此，在新设备克隆仓库后，需要重新配置 Obsidian 和相关插件。

# Markdown 笔记

> [!abstract] 简介
> Markdown 是一种轻量级标记语言。它使用少量符号表达标题、强调、链接、图片和代码等结构，适合用来编写技术文档与 Obsidian 笔记。

## 1. 标题

在文字前添加 `#` 可以创建标题，`#` 的数量代表标题层级：

```markdown
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
```

## 2. 文本样式

| 写法 | 效果 | 用途 |
| --- | --- | --- |
| `**粗体**` | **粗体** | 强调关键词 |
| `*斜体*` | *斜体* | 补充说明、术语 |
| `***粗斜体***` | ***粗斜体*** | 强烈强调 |
| `~~删除线~~` | ~~删除线~~ | 标记废弃内容 |
| `==高亮==` | ==高亮== | 标记重点 |
| `` `行内代码` `` | `行内代码` | 命令、变量或文件名 |

## 6. 行内代码与代码块

### 行内代码

使用一对反引号包裹短代码。例如，使用 `colcon build` 构建 ROS 2 工作空间，使用 `source install/setup.bash` 加载环境。

### 多行代码块

三个反引号可以创建代码块。在开头标注语言名称可以启用语法高亮。

```python
def greet(name: str) -> str:
    """生成一条问候语。"""
    return f"Hello, {name}!"


if __name__ == "__main__":
    print(greet("Markdown"))
```

## 7. 网页链接

基本写法为 `[显示文字](网址)`：

- [Markdown 官方语法说明](https://daringfireball.net/projects/markdown/syntax)
- [Obsidian 官方帮助文档](https://help.obsidian.md/)
- 自动链接：<https://www.ros.org/>

如需添加鼠标悬停提示，可以写成：

```markdown
[Obsidian](https://obsidian.md/ "Obsidian 官方网站")
```

## 8. Obsidian 内部链接

使用双方括号链接 Vault 内的其他笔记：

- `[[知识笔记/Python入门]]` → [[知识笔记/Python入门]]
- `[[知识笔记/Git笔记|Git 学习笔记]]` → [[知识笔记/Git笔记|Git 学习笔记]]
- `[[知识笔记/ROS2常用代码模版#常用命令]]`：链接到指定标题

在链接前添加 `!` 可以嵌入另一篇笔记或其中的某个章节：

```markdown

```

## 10. 表格

| 项目 | Markdown 写法 | 说明 |
| :--- | :---: | ---: |
| 左对齐 | `:---` | 内容靠左 |
| 居中 | `:---:` | 内容居中 |

表格中的竖线可使用反斜杠转义，例如 `\|`。

## 11. Callout 提示框

Obsidian 支持多种 Callout：

> [!note] 笔记
> 用于补充普通信息。

> [!info] 信息
> 用于提供背景或参考资料。

> [!success] 完成
> 操作已经成功完成。

> [!warning] 警告
> 执行危险操作前应当备份数据。

> [!bug] 问题记录
> 记录可以稳定复现的异常现象。

Callout 还可以折叠：

> [!example]- 点击展开示例
> 在类型后添加 `-`，默认保持折叠；添加 `+`，默认保持展开。

## 12. 数学公式

行内公式使用单个美元符号：质能方程为 $E=mc^2$。

独立公式使用两个美元符号：

$$
f(x)=\frac{1}{\sqrt{2\pi\sigma^2}}
\exp\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)
$$

## 13. 脚注

Markdown 可以使用脚注补充不适合放在正文中的信息。[^markdown]

也可以创建带名称的脚注。[^obsidian]

[^markdown]: Markdown 由 John Gruber 于 2004 年发布。
[^obsidian]: Obsidian 在 Markdown 基础上扩展了 Wiki 链接、Callout 和块引用等功能。

## 14. 注释与转义

Obsidian 注释不会出现在阅读视图中：

```markdown
%% 这是一段仅在编辑模式可见的注释。 %%
```

%% 这是本笔记中的实际注释，在阅读视图中不会显示。 %%

当需要显示 Markdown 特殊符号本身时，可以使用反斜杠转义：

```markdown
\*这不是斜体\*
\# 这不是标题
```

实际效果：\*这不是斜体\*，\# 这不是标题。

## 15. 推荐的笔记结构

一篇清晰的知识笔记通常可以按照以下顺序组织：

1. **问题或主题**：这篇笔记要解决什么问题？
2. **核心结论**：先给出最重要的答案。
3. **原理说明**：解释结论为什么成立。
4. **操作步骤**：使用列表和代码块记录过程。
5. **结果验证**：添加截图、命令输出或检查清单。
6. **参考资料**：添加网页链接与内部 Wiki 链接。
7. **后续任务**：用任务列表记录尚未完成的工作。

> [!summary] 小结
> Markdown 的重点不是记忆所有语法，而是使用标题建立层级、使用链接连接知识、使用代码块保留可执行内容，并通过适量的强调让信息更容易阅读。
